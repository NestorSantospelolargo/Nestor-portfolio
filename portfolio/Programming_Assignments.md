# Programming Assignments
## Python: Fast or Slow? Comparison of Pure Python vs. NumPy

This project compared the performance of pure Python and NumPy when performing vector and matrix multiplication.

### Reflection

The results demonstrated the importance of choosing appropriate tools and algorithms when solving computational problems. NumPy significantly outperformed pure Python for large numerical operations due to vectorization and optimized low-level implementation.
